==== Windows 2019 agent images have been dropped

For users who must use Windows for their agent images and are stuck on Windows
2019, the workaround is either to:

* Upgrade to Windows Server 2022 or Windows Server 2025
* Build their own agent image for Windows Server 2019

More details are available in the link:/blog/2026/08/21/win-2019-container-end-of-life/[blog post].
