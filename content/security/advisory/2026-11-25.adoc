  reporter: parameter.ai (http://github.com/parameter-ai-security)
  title: Sandbox bypass via interface field initializers in PLUGIN_NAME
  cve: CVE-2026-136834
  cvss:
    severity: High
    vector: CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H
  description: |-
    PLUGIN_NAME provides a sandbox feature that allows running user-provided scripts safely by intercepting and checking potentially unsafe operations.

    Sandbox protection in PLUGIN_NAME 4403.v471713a_cea_19 and earlier can be circumvented through interface field initializers.

- id: SECURITY-4278
  reporter: tracenull
  title: Sandbox bypass via partially qualified @Builder annotation name in PLUGIN_NAME
  cve: CVE-2026-136835
  cvss:
    severity: High
    vector: CVSS:3.1/AV:N/AC:H/PR:L/UI:N/S:U/C:H/I:H/A:H
  description: |-
    PLUGIN_NAME provides a sandbox feature that allows running user-provided Groovy scripts safely by intercepting and checking potentially unsafe operations.

    Groovy's `@Builder` annotation generates builder code at compile time using the strategy class named by its `builderStrategy` member, which can be one of the strategies provided by Groovy or a custom implementation.

    PLUGIN_NAME 1436.v1082791135e4 and earlier does not reject `@Builder` annotations whose `builderStrategy` member names an arbitrary class when the annotation is referred to using a partially qualified class name, which causes Groovy to instantiate that class at compile time, before the sandbox is applied.

    This may allow attackers with permission to define and run sandboxed scripts, including Pipelines, to execute code outside the sandbox, in the rare case that a suitable class is present on the classpath of the component that evaluates the script.

    NOTE: This issue is due to an incomplete fix of link:/security/advisory/2026-09-16/#SECURITY-3925%20(2)[SECURITY-3925 (2)].

    PLUGIN_NAME 1436.1438.v3dc5ef7d16f2 rejects `@Builder` annotations whose `builderStrategy` member names a class other than the builder strategies provided by Groovy when the annotation is referred to using a partially qualified class name, during sandbox compilation.
  plugins:
  - name: script-security
    previous: 1436.v1082791135e4
    fixed: 1436.1438.v3dc5ef7d16f2
