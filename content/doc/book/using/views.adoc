= Managing and Customizing Views

////
Pages to mark as deprecated by this document:

https://wiki.jenkins.io/display/JENKINS/Editing+or+Replacing+the+All+View
////

Jenkins views provide a way to organize, categorize, and filter projects on the main Jenkins dashboard.
In large installations with dozens or hundreds of jobs, views help users focus on relevant pipelines, team responsibilities, or specific release branches.

By default, Jenkins displays an **All** view that lists every job configured on the controller.
While convenient for initial setups, the default "All" view has a fixed layout that cannot be directly customized or reordered.
This guide explains how to create customizable views, customize column layouts, and set a custom view as the default dashboard view.

== The Default "All" View

When Jenkins is first installed, it automatically generates a view named **All**:

* It dynamically includes every project on the Jenkins controller.
* It displays default columns such as build status, weather forecast, project name, last success, last failure, last duration, and the build trigger icon.
* Unlike custom views, the default "All" view cannot have its columns edited, reordered, or removed directly through the web UI.

To customize the columns or behavior of your main Jenkins dashboard, administrators and users can create a new view that acts as an editable replacement for the "All" view.

== Creating an Editable Replacement View

To create a new view that includes all projects while allowing full customization of columns and filters:

1. On the Jenkins dashboard, click the **+** (New View) tab located next to existing view tabs.
2. In the **View name** field, enter a name for your new view (for example, `Dashboard`, `Overview`, or `Main`).
3. Under **Type**, select **List View**:
   * **List View**: A tabular list of projects that can be filtered and displays customizable status columns.
   * **My View**: Displays only jobs that the current user has permissions to see or that are relevant to the user.
4. Click **Create** to open the view configuration screen.
5. In the view configuration, scroll to the **Job Filters** section.
6. Check **Use a regular expression to include jobs into the view**.
7. In the **Regular expression** field, enter `.*`.
+
[TIP]
====
Entering `.*` matches any project name, ensuring that all existing projects and any newly created projects are automatically included in this view without requiring manual selection.
====
8. Scroll down and click **Save**.

Your new view is now created and populates all projects on the controller.

== Customizing View Columns

Unlike the default "All" view, custom List Views allow administrators and users to fully configure which columns appear on screen and in what order:

1. Navigate to your custom view tab on the dashboard.
2. In the left navigation menu, click **Edit View**.
3. Scroll to the **Columns** section.
4. To remove an unwanted column (such as the Weather report or Last Duration), click the **Delete** button next to that column.
5. To reorder columns, drag and drop the grabber handle next to any column up or down.
6. To add new columns, click **Add column** at the bottom of the column list and select from available options:
   * **Status**: Displays the build status icon (blue/green, red, yellow).
   * **Weather**: Visual indicator of recent build stability.
   * **Name**: The project name and link.
   * **Last Success**: Timestamp of the most recent successful build.
   * **Last Failure**: Timestamp of the most recent failed build.
   * **Last Duration**: Duration of the most recent build execution.
   * **Build Button**: One-click icon to trigger a build directly from the dashboard.
   * **Project Description**: Displays the project description under the name.
   * Additional columns contributed by installed plugins (such as Git branch, code coverage, or test results).
7. Click **Save** to apply your column customizations.

== Setting a Custom View as the Default Dashboard

Once a replacement view is configured, administrators can set it as the primary view displayed when users navigate to the Jenkins root URL.

=== System-Wide Default View

To change the default view for all users across the Jenkins instance:

1. Ensure that you have already created at least one custom view.
2. Navigate to **Manage Jenkins** > **System**.
3. Scroll to the **Default View** dropdown in the global configuration section.
4. Select your custom view name from the dropdown.
5. Click **Save**.

When users navigate to the Jenkins home page, the selected custom view will now display by default instead of the built-in "All" view.

=== Removing the Original "All" View

Once a new default view has been configured, administrators may choose to remove the original, un-customized "All" view tab to avoid dashboard clutter:

1. Ensure that the original "All" view is no longer selected as the default view.
2. Click on the **All** tab.
3. In the left navigation menu, click **Delete View**.
4. Confirm the deletion when prompted.

[NOTE]
====
Deleting the "All" view does *not* delete any jobs or projects.
It only removes the dashboard tab.
Projects will continue to exist and appear in your replacement view.
====

== User-Specific "My Views"

In addition to system-wide views, Jenkins allows individual users to maintain their own personal views:

1. In the top navigation bar, click on your username or navigate to **People** > select your username.
2. Click **My Views** in the left sidebar.
3. Users can create personal views (such as a List View filtering jobs they own or work on) following the same process as system views.
4. A user can set a personal default view under their user profile configuration (**Configure** > **Default View**).
