= Using Jenkins

This chapter contains topics for typical Jenkins users (of all skill levels)
on working with Jenkins day-to-day.

== Topics in this chapter

link:best-practices[Best Practices]::
Recommendations for structuring jobs and pipelines effectively.

link:working-with-projects[Working with projects]::
Creating, copying, renaming, and moving Jenkins projects.

link:views[Managing and Customizing Views]::
Organizing, categorizing, and filtering projects into custom dashboard views and replacing the default "All" view.

link:using-credentials[Using Credentials]::
Managing and using credentials such as SSH keys, usernames with passwords, and secret text.

link:feature-previews[Enabling feature previews]::
Choose experimental features for your Jenkins account, or learn how administrators can set controller defaults.

link:searchbox[Using Command Palette]::
Using the search box and Command Palette to navigate jobs, views, and administration pages.

link:using-agents[Using Agents]::
Executing builds across distributed agents.
